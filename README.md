# Treasury Portal

A treasury management web app for the Yale Political Union: members submit
reimbursements, treasurers review and pay them, and the org gets a public
ledger, budget tracking, and analytics — replacing the old Google Forms +
Excel workflow.

## Tech stack

- Next.js 15 (App Router) + React 19 + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase: Auth (Google OAuth), Storage, Postgres
- Prisma ORM
